**Responsive Login & Signup Form with Validation**

-] This project is a responsive login and signup form built using HTML, CSS, and vanilla JavaScript.
-] It is based on a sliding UI template that switches between Login and Signup forms, and secure output handling.

FEATURES
-> Responsive login & signup UI.
-> Smooth sliding animation between forms.
-> Live email and password validation.
-> Validation on form submission.
-> Error messages for invalid input.
-> Displays entered login details after successful. validation
-> Clean separation of HTML, CSS, and JavaScript.

VALIDATION RULES

Email:
-] Required
-] Must follow a valid email format (username@email.com)

Password:
-> Required
-> Minimum 8 characters
-> Must contain uppercase, lowercase, and a number

TECHNOLOGIES USED
-] HTML5
-] CSS3
-] JavaScript (Vanilla)

PROJECT STRUCTURE
-> index.html
-> style.css
-> script1.js
-> README.txt

HOW IT WORKS
-] Inputs are validated live as the user types.
-] Invalid inputs are highlighted through textboxes.
-] On submit, errors are shown or success output is displayed

HOW TO RUN
-> Download the project.
-> Open index.html in a browser.
-> No server required.

NOTES
-] Frontend-only project.
-] Passwords are masked in output.
-] For learning purposes only.
